# takoyaki0 entry

入門用(entry)の8キーのキーボードです。takoyakeeb の機種の1つです。

- キー: MX スイッチ 8個(4×2)、ホットスワップ
- マイコン: Waveshare RP2040-Zero(ピンヘッダーで取り付け)
- 部品はスルーホールが中心で、ハンダ付けが初めての人でも組み立てやすい形を目指しています
