## takoyaki0.pretty(フットプリント)

### RP2040-Zero_PinHeader

- 用途: RP2040-Zero を、付属のピンヘッダーで、基板の表面に、部品面を上にして付ける。USB-C は上(基板の奥)向き
- 出典: 自作(2026-11-16)
- 穴: 23個すべてにパッド(穴 φ1.0、パッド φ1.7、1番だけ四角)
- 寸法の根拠: Waveshare 公式の外形寸法図(外形 18.00 × 23.50mm、左右の列の間隔 15.24mm、上の端から 1.59mm が1本目、2.54mm ピッチ)。列の間隔は、ブレッドボードで実物でも確認した
- 手前の辺(10〜14)は、9番・15番と同じ高さ(Y = +10.16)。7つの穴が一直線なことは、2026-11-16 に確認した

### SW_MX_HS_CPG151101S11_1u

- 用途: MX スイッチ用、Kailh のホットスワップソケット CPG151101S11 のフットプリント(1u)
- 出典: marbastlib の `marbastlib-mx`(ebastler/marbastlib、CERN-OHL-P-2.0)から、2026-11-18 にコピー。中身は変えていない
- ソケットのパッドは F.Cu 側にある(ソケットの側から見た形)。ソケットは基板の裏面に付けるので、裏返して B.Cu 側に置く
- 同じライブラリの `SW_MX_HS_S_CPG151101S11_1u` は、穴とパッドがまったく同じで、シルクだけが短い。ソケットの外形をシルクで見せたいので、こちら(外形のシルクがある方)を使う

| 項目 | 値(ソケットの側から見た座標) |
|---|---|
| キー間隔 | 19.05mm(Dwgs.User の枠) |
| 中央の穴 | φ3.9878(NPTH) |
| 5ピン用の足の穴 | φ1.75(NPTH)、(−5.08, 0) と (5.08, 0) |
| スイッチのピンの穴 | φ3.0(パッド φ3.3)、(3.81, −2.54) と (−2.54, −5.08)。表から見ると左右が反転して、(−3.81, −2.54) と (2.54, −5.08) |
| ソケットのパッド | 2.55 × 2.5mm、(7.36, −2.54) と (−6.09, −5.08) |
| プレートの穴 | 14.0 × 14.0mm、角 R0.5(Eco2.User) |
| 3D モデル | `${KICAD8_3RD_PARTY}` のパスのまま(marbastlib を入れていないと表示されない。設計には影響しない) |

実物の確認: まだ(ソケットとスイッチが届いたら、1:1 の印刷に重ねて確かめる)。
